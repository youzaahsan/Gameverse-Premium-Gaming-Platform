# 🎮 GameVerse – Premium Gaming Landing Page

GameVerse is a next-generation gaming landing page built with React.js, Vite, Tailwind CSS, Framer Motion, and React Icons. Designed with a futuristic gaming aesthetic, immersive animations, neon glow effects, glassmorphism UI, and AAA-level presentation, this project delivers a premium experience inspired by modern esports and gaming platforms.

---

## 🚀 Project Overview

GameVerse is a production-ready gaming website that combines cutting-edge UI/UX design with high-performance frontend technologies. The platform showcases featured games, esports tournaments, community engagement, live statistics, gaming galleries, and AI-powered gaming tools in a visually stunning environment.

The goal of this project is to create a website that feels like the official platform of a multi-million-dollar gaming company.

## 📦 Installation

Clone Repository

```bash
git clone https://github.com/your-username/gameverse.git
```

Navigate to Project

```bash
cd gameverse
```

Install Dependencies

```bash
npm install
```

Run Development Server

```bash
npm run dev
```

Build for Production

```bash
npm run build
```
